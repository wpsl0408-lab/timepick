## 1. 서비스 개요

**TimePick**은 한신대학교 주변 맛집을 대상으로 실시간 대기시간 예측 및 웨이팅 등록 서비스를 제공하는 스마트 관광 플랫폼입니다.

카카오맵 API와 기상청 Open API를 결합하여 날씨·요일·시간대에 따른 혼잡도를 예측하고, Google Gemini AI가 현재 상황에 맞는 맛집을 자동 추천합니다. 사용자는 현장 정보를 공유하고 포인트를 적립하여 제휴 식당 교환권으로 사용할 수 있습니다.

| 항목 | 내용 |
|------|------|
| 서비스명 | TimePick |
| 서비스 유형 | 모바일 웹 (PWA) |
| 타겟 지역 | 경기도 오산시 한신대학교 주변 |
| 주요 타겟 | 한신대 재학생 및 인근 방문객 |
| 플랫폼 | GitHub Pages (웹) |

## 2. 문제 정의

### 2-1. 예측 불가한 대기시간

식당 앞에 직접 방문해야만 대기시간을 알 수 있어 헛걸음이 반복됩니다. 특히 점심·저녁 피크타임에는 30분 이상 대기하는 경우가 빈번하며, 이는 학생 및 방문객의 시간 낭비로 이어집니다.

### 2-2. 주변 맛집 통합 정보 부재

한신대 주변 맛집 정보가 여러 플랫폼에 분산되어 있어 한눈에 비교하기 어렵습니다. 실시간 혼잡도·대기시간을 함께 확인할 수 있는 통합 플랫폼이 없습니다.

### 2-3. 방문 동기 및 참여 유인 부족

리뷰를 작성하거나 현장 정보를 공유해도 사용자에게 돌아오는 직접적인 혜택이 없어 플랫폼 내 적극적인 참여가 이루어지지 않습니다.

## 3. 솔루션

### 3-1. 빅데이터 기반 대기시간 예측

요일·시간대·날씨 데이터를 결합한 알고리즘으로 방문 전 예상 대기시간을 제공합니다. 기상청 Open API를 실시간 연동하여 날씨 변화에 따른 혼잡도 보정을 자동 적용합니다.

```
예측 공식: 최종 대기시간 = 기본 대기 × (1 + 날씨 보정% + 요일 보정% + 시간대 보정%)

날씨 보정: 맑음 +15% / 흐림 -5% / 비 -20% / 눈 -25%
요일 보정: 토요일 +25% / 일요일 +20% / 금요일 +15% / 월·화 -10%
시간대 보정: 점심(11~13시) +30% / 저녁(17~19시) +25%
```

### 3-2. 카카오맵 기반 위치 서비스

GPS로 현재 위치를 파악하고, 키워드 검색으로 정확한 식당 좌표를 자동으로 찾아 지도에 표시합니다. 마커 클릭 시 해당 식당의 실시간 대기정보를 즉시 확인할 수 있습니다.

### 3-3. 비대면 웨이팅 등록

현장 방문 없이 앱에서 웨이팅을 등록하고, 순서가 되면 알림을 받을 수 있습니다. 날씨·요일·시간대를 반영한 예상 대기시간을 확인한 후 등록 여부를 결정할 수 있습니다.

### 3-4. 포인트 리워드 생태계

현장 정보 공유 및 리뷰 작성 시 즉시 포인트를 지급하여 사용자 참여를 유도합니다. 적립된 포인트는 제휴 식당 교환권으로 사용 가능하여 재방문을 촉진합니다.

## 4. 핵심 기능

### 🗺️ 카카오맵 연동 맛집 탐색
- 현재 위치 기반 주변 식당 마커 자동 표시
- 카카오맵 키워드 검색으로 정확한 좌표 자동 탐색
- 마커 클릭 → 식당 상세 정보 즉시 확인

### ⏳ 실시간 대기시간 예측
- 날씨·요일·시간대 3중 보정 알고리즘 적용
- 시간대별 혼잡도 그래프 시각화
- 최적 방문 시간 자동 추천

### 🌤️ 기상청 날씨 API 연동
- 기상청 단기예보 Open API 실시간 연동
- 현재 기온·날씨 상태 헤더 위젯 표시
- 날씨 변화에 따른 대기시간 보정 자동 반영

### 🤖 Gemini AI 맛집 추천
- Google Gemini 2.0 Flash API 연동
- 현재 날씨·시간대·대기시간 데이터를 AI가 종합 분석
- 상황에 최적화된 맛집 1줄 추천 자동 생성

### 📋 웨이팅 등록 시스템
- 비대면 웨이팅 등록 및 순번 확인
- 날씨 보정 예상 대기시간 실시간 표시
- 등록 완료 알림 기능

### 💰 포인트 리워드 시스템
- 현장 정보 공유 시 300P 즉시 지급
- 리워드샵에서 제휴 식당 교환권으로 사용
- 포인트 적립 애니메이션으로 즉각적인 피드백 제공

### 🏪 사장님 관리 대시보드
- 대기시간·혼잡도 실시간 업데이트
- 가게 정보 등록 및 수정
- 광고 문구 관리 및 쿠폰 발행

```

   ├── 기상청 날씨 위젯

   └── 인기 식당 리스트
       ↓
4. 식당 상세 페이지
   ├── 날씨 보정 대기시간 표시
   ├── 카카오맵 위치 확인
   ├── 시간대별 혼잡도 그래프
   └── 최적 방문 시간 추천
```

## 7. 비즈니스 모델

### 7-1. 입점 구독료 (B2B)
플랫폼에 식당을 등록하는 사장님 대상 월정액 구독 서비스입니다.

- 기본 플랜: 월 9,900원 (대시보드·대기시간 관리)
- 프리미엄 플랜: 월 29,900원 (광고 노출·쿠폰 발행·분석 리포트 포함) -> 추후 예정(미정)

### 7-2. 광고 수익 (B2B)
대기시간이 긴 식당 근처에 경쟁 식당 광고를 노출하는 CPC(클릭당 과금) 방식입니다.

- 맛집 추천 배너 광고
- AI 추천 시 스폰서 식당 우선 노출
- 예상 클릭단가: 50~200원

### 7-3. 포인트 생태계 수익 (B2C)
- 교환권 발행 수수료: 거래액의 5%
- 미사용 포인트 소멸 수익
- 포인트 구매 옵션 (현금 충전)

## 9. 기대 효과 및 차별점

### 사용자 측면
- 방문 전 대기시간 파악으로 **헛걸음 40% 감소** 예상
- 비대면 웨이팅으로 현장 대기 불편 해소
- 포인트 리워드로 플랫폼 재방문율 향상

### 식당 측면
- 웨이팅 시스템으로 고객 이탈 감소
- 광고·쿠폰으로 신규 고객 유입 **+25%** 예상
- 사장님 대시보드로 실시간 매장 관리 효율화

### 기술적 차별점

1. 날씨 연동 대기시간 예측: 기상청 API + 대기시간 예측을 결합한 3중 보정 알고리즘
2. Gemini AI 실시간 추천: 현재 날씨·시간·대기 상황을 종합 분석한 맞춤 추천
3. 카카오맵 키워드 자동 탐색: 하드코딩 좌표 없이 실시간 정확한 위치 탐색
4. 지역 특화 서비스: 한신대 주변 맛집에 특화된 데이터 및 UI
